PRESENTACIÓN ROMÁNTICA - VS CODE

1. Abre esta carpeta en Visual Studio Code.
2. Abre index.html con Live Server (recomendado) o directamente en el navegador.
3. El proyecto empieza con una espera de 10 segundos.
4. Aparece la tarjeta inspirada en el video.
5. Pulsa "Abrir" para la animación de apertura.
6. Después aparece la sorpresa del mes de dúos.

ARCHIVOS:
- index.html = contenido y estructura
- style.css = diseño y animaciones
- script.js = temporizador y secuencia

PERSONALIZACIÓN:
- Cambia los textos de index.html.
- Cambia "DUO-1-MES-❤️" por tu código real.
- Puedes sustituir los emojis por tus propias imágenes/fotos.
